# 🎨 Elysia Anime Design Collection

Koleksi lengkap 30 desain UI bertema anime yang siap diintegrasikan dengan **ElysiaJS** untuk pengembangan fullstack.

## 📦 Isi Project

### 🌟 Landing Pages (10 Desain)
1. **Hero Anime** - Tema superhero dengan power levels
2. **Magical Girl** - Tema magical girl dengan transformasi
3. **Mecha** - Tema robot futuristik
4. **School Anime** - Tema kehidupan sekolah dengan sakura
5. **Fantasy** - Tema dunia mistis dengan sihir
6. **Gaming** - Tema dunia virtual gaming
7. **Cyberpunk** - Tema kota neon masa depan
8. **Slice of Life** - Tema kehidupan sehari-hari
9. **Action** - Tema pertempuran intens
10. **Romance** - Tema cerita cinta

### 🔐 Login Pages (10 Desain)
Setiap tema memiliki halaman login yang matching dengan konsepnya

### 📊 Dashboards (10 Desain)
Dashboard lengkap dengan sidebar, stats cards, dan content grid untuk setiap tema

## 🚀 Cara Menggunakan

### Lokal Development
```bash
# Clone repository
git clone https://github.com/pendtiumpraz/project-elysia.git

# Buka folder
cd project-elysia

# Buka index.html di browser
```

### Integrasi dengan ElysiaJS
```bash
# Install ElysiaJS
bun install elysia

# Setup server
bun run src/index.ts
```
